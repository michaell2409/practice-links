# practice-links 🔗

A small exercise I did at school to learn how to use links, and one more step on my way to becoming a better developer.

Every website you visit is built on one simple idea: connecting things. A link can take you to another site, jump to a different part of the same page, open your email or download a file. In this project I practised all of them, one tag at a time.

## What I learned

- **External links**: opening pages in the same tab or in a new one (`target="_blank"`)
- **Internal links**: using `id` and `#` to jump between sections of the same page
- **Nested lists**: building an index with `<ol>` inside `<ol>`
- **Download links**: letting visitors download files with `download`
- **Email links**: opening the mail app with `mailto:`
- **Image links**: turning an image into a clickable link

## Why is the page in Spanish?

I'm a student of Microcomputer Systems and Networks (SMR) at IES Lomo de la Herradura in the Canary Islands, Spain. The exercise was given in Spanish by my teacher, so I kept the original content to stay faithful to the task. The code, however, speaks a universal language: HTML works the same in every country.
